# MYOURISCOPE — 統合占いプラットフォーム

西洋占星術・四柱推命・九星気学・タロット・相性の占術を統合した占いWebアプリ。
純粋な静的サイト(HTML/CSS/JS + localStorage)で、外部API・サーバーなしで動作します。

## 公開URL

- 本番: https://myouriscope.com/ (GitHub Pages + 独自ドメイン / pushで自動デプロイ)
- 旧URL: https://hidaka86.github.io/fortune/ (独自ドメイン有効化後は自動リダイレクト)

## 主な機能

| 機能 | 内容 |
|------|------|
| 運命の称号 | 日主(10)×太陽星座(12)×本命星(9)=1080タイプの固有の二つ名 |
| 統合鑑定 | 占術横断レポート+称号+シェアカード(1200x630)プレビュー |
| ホロスコープ | 出生図:10天体の星座配置(Schlyter近似)+主要アスペクト+チャートホイールSVG |
| 今日の結論 | 日運・月運・干支の巡り・月相の4手法の合議で「攻めの日/整えの日」等を判定 |
| マイページ | 気の流れ(日/週/月)・吉方位コンパス・称号図鑑・鑑定履歴・連続日数 |
| タロット | 78枚フルデッキ(大アルカナ22+小アルカナ56)・テーマ別解釈・今日の一枚は1日1回制・フルスクリーンの儀式フロー(シャッフル→カット→ドロー→リビール) |
| 相性診断 | 称号×称号、双方向の見え方、関係を一言キーワード化 |
| アストロダイス | 全画面の「ダイスの間」で三つの12面体を自分の手で振る(押さえて・振って・はなす→物理演算で転がる)。出目を順に読み解き「なにが・どのように・どこで」を読む |
| マヤ暦 | 生年月日からKIN・太陽の紋章・銀河の音・ウェイブスペル・運命のオラクル、今日のKINとの関係と過ごし方、お相手との関係 |
| 招待リンク | シェアURLに称号を埋め込み、開いた人に「招待状」を表示 |
| PWA | ホーム画面追加・オフライン対応(Service Worker)・専用アイコン |

## 占術ロジック(検証済み)

- 日柱: ユリウス通日から六十干支を連続計算(1900-01-01=甲戌, 2000-01-01=戊午でアンカー検証)
- 月柱: 簡易節入り+五虎遁 / 年柱: 立春前は前年扱い
- 通変星: 日主×巡る干で10種を判定し、日運・月運・年運と運勢スコアの根拠に使用
- 吉方位: 月盤(年支グループ→寅月中宮→毎月逆行)から五黄殺・暗剣殺・本命殺・本命的殺を除外
- 月星座: 正午JSTの月黄経(主要4摂動項)で判定
- 今日の運勢: 通変星+月相補正+シード付き微小ゆらぎ(同じ日は同じ結果、理由も表示)

## 使い方

ビルド不要。`index.html` をブラウザで開くだけで動きます。

```bash
python3 -m http.server 8000  # → http://localhost:8000
```

## 構成

```
index.html      # SPA本体
css/style.css   # デザインシステム「月光ミスティック」(深紺×金×紫・明朝体)
css/lp.css      # 検索流入用LPの差分スタイル
js/data.js      # 占術データ(星座・九星・タロット・通変星・称号)
js/fortune.js   # 計算ロジック(四柱・九星・月星座・判定エンジン)
js/icons.js     # SVGアイコン定義(五行・月相・天体・星座・装飾、currentColor)
js/mystic.js    # 演出レイヤー(粒子・スクロール出現・観測演出・月相SVG・環境音)
js/app.js       # UI(マイページ・シェア・図鑑・PWA)
js/extra.js     # アストロダイス・マヤ暦(データ+ロジック+UI)
assets/         # 素材(配置場所は assets/README.md を参照)
scripts/build-icons.mjs  # js/icons.js から単体SVGを書き出す
icons-preview.html       # SVGアイコン一覧(確認用・noindex)
today/ tarot/ horoscope/ shichusuimei/ aisho/ shogo/
                # 検索流入用の静的ランディングページ(SEOの入口)
seiza/          # 12星座の一覧+星座別ページ13本(data.jsのZODIACと同値)
tarot/cards/    # タロット78枚の意味ページ+一覧(本文はdata.jsから抽出)
sitemap.xml     # サイトマップ(LP追加時はここに追記)
robots.txt      # クローラ設定
404.html        # Not Foundページ
sw.js           # Service Worker
manifest.json   # PWAマニフェスト
icons/          # アプリアイコン
```

デプロイはpushで自動(GitHub Actions → GitHub Pages)。CSS/JSはコミットSHAでキャッシュバスティングされます。

> 占い結果はエンターテインメントとしてお楽しみください。
