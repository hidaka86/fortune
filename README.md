# Fortuna — 統合占いプラットフォーム(プロトタイプ)

西洋占星術・東洋占術・タロット・手相の4占術をひとつに統合した占いWebアプリのプロトタイプです。

## 機能

| 機能 | 内容 |
|------|------|
| 統合鑑定 | 六占術を横断した総合レポート+シェア画像生成(Canvas) |
| 星占い | 太陽星座+月星座(月の黄経を略算で天文計算) |
| 東洋占術 | 四柱推命の三柱(年柱・月柱・日柱/日主)+九星気学+干支 |
| タロット | 大アルカナ22枚。今日の一枚 / 過去・現在・未来の3枚スプレッド |
| 手相 | 生命線・頭脳線・感情線・運命線の特徴から診断(SVG図連動) |
| 相性診断 | 星座エレメント×五行(相生・相剋)×干支(三合・支合・冲)の3面採点 |

- 「今日の運勢」は生年月日×日付のシード値で決定論的に生成(同じ日は同じ結果)
- 日柱はユリウス通日から六十干支を連続計算(1900-01-01=甲戌, 2000-01-01=戊午で検証済み)
- 月柱は簡易節入り日+五虎遁、干支・九星は立春前生まれを前年扱いにする簡易補正入り
- 月星座は正午JST時点の月黄経(主要4摂動項)で判定。境界日は前後の星座の可能性あり
- ホームは日替わりで月相・今日の言葉が変わり、鑑定結果には他占術への回遊導線付き

## 使い方

ビルド不要。`index.html` をブラウザで開くだけで動きます。

```bash
# ローカルサーバーを立てる場合
python3 -m http.server 8000
# → http://localhost:8000
```

## 構成

```
index.html      # SPA本体(タブ切り替え式)
css/style.css   # デザインシステム(ダークテーマ)
js/data.js      # 占術データ(星座・九星・タロット・手相)
js/fortune.js   # 計算ロジック(星座判定・九星計算・シード乱数)
js/app.js       # UIロジック(ナビゲーション・レンダリング)
```
