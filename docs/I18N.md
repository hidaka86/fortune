# MYOURISCOPE 多言語対応(日英)実装規約

> 最終更新: 2026-07-14
> 対象: js/i18n.js / js/data.en.js / js/app.js / js/fortune.js / index.html

## 1. アーキテクチャ

ビルド無しの静的サイトのまま、**ランタイムで言語を切り替える**。

| ファイル | 役割 |
|---|---|
| `js/i18n.js` | 言語判定(`?lang=` → `localStorage(ms_lang)` → 地域: タイムゾーンが Asia/Tokyo 以外なら EN → ブラウザ言語)。`L()/NM()/NMK()/cardName()/fmtMD()/fmtYMD()/fmtWD()/whoLabel()` を定義。index.html の静的テキストを `data-i18n` 属性で差し替え。ヘッダーに言語切替ボタンを注入 |
| `js/data.en.js` | **英語時のみ読み込まれる**(index.html が `I18N.en` を見て document.write)。data.js が定義したオブジェクトの**表示用フィールドだけ**を英語に書き換える(ミューテーション) |
| `js/app.js` / `js/fortune.js` | 文中に埋め込まれた日本語を `L("日本語", "English")` で二言語化。日本語文字列は**1バイトも変えない** |

読み込み順: `i18n.js` → `data.js` → `fortune.js` → (`data.en.js` if EN) → `app.js`

## 2. 鉄則

1. **日本語の挙動は完全不変。** `L(ja, en)` の ja 側は既存文字列をそのままコピーする。
2. **キーとして使われる値は絶対に書き換えない。** 具体的には:
   - `ZODIAC[i].name` / `KYUSEI[i].name` / `ETO[i].name` / `MOON_PHASES[i].name` / `DIRECTIONS[i].name`
   - `TSUHENSEI` のキー(比肩〜印綬)と `tsuhensei()` が返す `star.name`
   - `dailyVerdict()` の `rank`(大吉/吉/平/静/休)— `MIND_WORDS[rank]` や `v.rank === "大吉"` 比較に使われる
   - `RITUAL_SPREADS` / `TAROT_SPREADS` のキーと `count/gate/once` 等の制御フィールド
   - localStorage キー・`data-nav` 値・CSSクラス名
   これらは**表示する瞬間に** `NM(value)` / `NMK(kanshi)` で英語化する。
3. **曜日の一文字(日月火水木金土)に `NM()` を使わない**(五行の文字と衝突)。曜日は `fmtWD(dateObj.getDay())` を使う。
4. タロットカード名の表示は `cardName(card)`(EN時は `card.en`)。`card.name` を直接表示しない。
5. 日付表示は `fmtMD(m, d)` / `fmtYMD(y, m, d)`。「◯月」単独は `L()` で文ごと二言語化。
6. 呼びかけ(「◯◯さん」/「あなた」)は `whoLabel(p.name)`。英語で文頭に来る場合の大文字化は文側で調整。
7. テンプレートリテラル内の日本語は文単位で `L()` に包む: `` L(`今日は${x}の日`, `Today is a ${NM(x)} day`) ``。英語側では挿入される日本語の変数を必ず `NM()/NMK()/cardName()` で包むこと。
8. `data.en.js` は**ミューテーション文のみ**を書く(例: `TAROT[0].up = "..."`)。`name` 等のキーには触れない。実行時は EN 確定なので言語判定は不要。

## 4. 英語コピーのトーン(ブランドボイス)

- **Divination as observation, not decree.** 断定しない・脅さない・煽らない。"You will…" より "The current favors…" / "This is a day for…"。
- 読者は "you"。あたたかく、静かで、文学的すぎない平易な英語。朝そっと背中を押す声。
- 大げさなスピリチュアル語彙(destiny is sealed, cosmic energy 等)や ALL CAPS、感嘆符の乱用は避ける。
- 語りかけは短い文で。日本語の「〜していい日」は "a day when it's okay to…" / "permission to…" のニュアンス。
- 文化的固有概念(干支・九星など)は正準訳+さりげない言い添えで伝わるように。直訳調・翻訳調を避け、英語として自然に。

## 5. SEO / 計測

- `<link rel="alternate" hreflang>` で `/`(ja)と `/?lang=en` を相互参照(index.html)。
- 言語切替イベントは GA4 に `lang_switch` として送信(i18n.js)。
