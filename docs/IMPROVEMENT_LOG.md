# 自律改善ループ 運用台帳

このファイルは、自律サイト改善ループ(評価→選定→実装→検証→コミット&プッシュ)の記録。
各サイクルの実施内容をここに追記する。バックログは `IMPROVEMENT_BACKLOG.md`。

## ループの設計

1. **評価**: 視点の異なるレビューエージェント(初心者UX / コピー・世界観 / SEO・パフォーマンス技術)が並列でサイトを巡回・検査し、改善候補を挙げる
2. **選定**: 候補を「期待効果 × 工数 × 確信度」で採点してバックログに統合し、上位1〜2件を選ぶ
3. **実装**: 選んだ項目を実装(PRODUCT.md の思想・デザイン原則に反する変更はしない)
4. **検証**: ローカルサーバー + Playwright / Node ロジックテストで確認。NGなら差し戻し
5. **記録とプッシュ**: このログに追記し、`claude/autonomous-site-improvement-loop-tikt0g` にコミット&プッシュ
6. 一定時間後に次サイクルを自動再開(セルフスケジューリング)

### 原則

- 1サイクルの変更は小さく保つ(レビュー可能な粒度)
- 「無料」等の煽り表現・課金誘導・派手な装飾は提案されても採用しない
- 検証に通らない変更はコミットしない
- 同じ指摘が複数視点から挙がったものを優先する
