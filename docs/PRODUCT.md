## 1. コンセプトと思想

- **占いは、決定ではなく観測。** 断定しない・脅さない・買わせない。毎朝そっと背中を押す。
- **1日1回の楽しみを守る。** 今日の一枚は1日1回だけ。引き直し不可。
- **結果のネタバレをしない。** 未観測の日の結果は再訪FVに表示しない。
- **根拠を見せる。** スコア・結論には必ず「どう計算したか」を添える(票の内訳、計算式、称号の由来)。
- **データは端末の中だけ。** 生年月日・履歴・図鑑はすべて localStorage。サーバー送信なし。
- 商業的な煽り表現(「無料」等)は使わない。

## 4. タロット

- **フルデッキ78枚**: 大アルカナ22(`tarot_00_fool.webp` 等)+小アルカナ56(`tarot_{suit}_{rank}.webp`、suit=wands/cups/swords/pentacles、rank=ace,02..10,page,knight,queen,king)。全カードに正位置/逆位置/助言テキスト。
- **スプレッド**(`RITUAL_SPREADS`): 今日の一枚(トップ専用・1日1回)/ワンオラクル(1枚・目の前のこと)/3枚(過去現在未来)/ケルト十字(10枚・DEEP)。
- **スプレッド選択UI**: 「夜の窓」カード(背景に対応アルカナ: ワンオラクル=魔術師、3枚=運命の輪、ケルト=月)。**タップ=即儀式開始**の1工程。
- **シャッフル(2方式・端末に保存 `fortuna:shufmode`)**:
  - **散らして選ぶ**(デフォルト): 34枚が全画面に散らばり、指の軌跡が物理演算(慣性+摩擦+常時ゆらぎ+カード同士の反発)で札を押し流す。タップでピック、規定枚数で自動リビール。
  - **重ねて混ぜる**: 長押しシャッフル(長押し時間とこする速さで加速)→3山カット→帯カルーセルからドロー。
- **シード思想**: 乱数は機械任せにしない。指を離した時刻・カットの選択・引いた位置・かき混ぜの軌跡を混ぜて `seededRng` に投入。
- **結果**: 結論カード「つまり、こういうこと」(word/reason/action)→各カード詳細(正逆両義)→デッキ深読み(大アルカナ比・スート偏り・正逆比・組み合わせ)→シェア。
- **結論の言い回し**は `TAROT_CONCLUSION_VOICE`(スプレッド×正逆ごとに3〜4種のプール、シード=日付×出た札)。同じ読みは何度開いても同じ言葉、別の読みなら別の言葉。
- **リビール**: タップで早送り、SKIP» ピルあり。1画面に収まる dvh 設計。

### タロット・緩急の仕掛け(エンゲージメント設計)

> 設計原則: **急がせる理由は「アプリの都合」ではなく「世界観(空)の都合」に置く。** 引き直し課金・FOMOカウントダウン等の不安につけ込む形は採らない。

**のんびり側(深さ・熟成)**
- **呼吸シャッフル**: 「重ねて混ぜる」長押し中に「吸って→とめて→吐いて」の呼吸ガイド。1呼吸(約9.4秒)以上で `ritual.deepShuffle`、結果に「☽ 深く混ぜられたデッキから」の印。
- **月の間**(`RITUAL_SPREADS.night`): 22:00〜3:59だけ開く3枚スプレッド(手放すこと/夜の本音/明日への灯)。昼はロック表示で「今夜22:00にひらく」。一夜に一回(深夜0〜3時は前夜と同じ夜として `nightWindow().key` で判定)。儀式の間はさらに深い夜(`.ritual-night`)。
- **熟成する託宣**: ジャーナルの各記録は 12時間後に「ふたつめの意味」(先頭札の逆側の顔)、3日後に「振り返りの問い」(自分で意味づけする入力欄)がひらく。1回の抽選を3回の再訪に変える。
- **振り返りの呼びかけ**: 7日以上前で振り返り未記入の記録があると、タロット画面に「◯日前、あなたは『塔』を引きました」カードを表示。

**急ぎ側(希少性・旬)**
- **宙の窓**(`celestialWindows()`): 新月の日だけ「新月の窓」(はじまりの一枚)、満月の日だけ「満月の窓」(手放しの一枚)が出現。締切は月齢=「この窓は今夜まで」。1日1回、消化後はロック表示。
- **消える託宣**: 読みの言葉(結論・理由)は**24時間で薄れる**。ひとこと書き残す(memo)と定着。薄れた記録は札の名前だけが残る。
- **風のざわめき**(`windCallToday()`): `seededRng(日付+"|windcall") < 0.125`(年約46日)で全員共通に発生。当日はホーム/タロットにバナー、読みの結果に「ざわめきの一枚」(日付+出た札シードのボーナス1枚。再表示でも同じ札=スロット化させない)。
- **水星逆行**(`isMercuryRetrograde()`): 今日と明日の水星黄経の差で判定。逆行中は問いかけ画面に注意書き。

**週のリズム**(`tarotTempoLine()`): 平日=ワンオラクル推し/金土19時以降=ケルト十字推し(「きょうの誘い」バッジ)/日曜=ジャーナルの読み返し推し/22時以降=月の間の案内。毎日同じテンポにしない。

### タロット・ジャーナル(託宣の記録)
- `fortuna:journal`(最大60件)。エントリ: `{id, t, spread, genre, q, cards, word, reason, memo, reflection}`。
- 状態遷移は `journalState()`: 薄れ(24h・memoで回避)/ふたつめの意味(12h)/振り返り(72h)。
- スプレッド完了時に自動保存(今日の一枚は today 画面が担当するため対象外)。結果画面下に「いま、書き残しておく」導線。

## 5. 今日の占い(今日の結論)

`dailyVerdict(birthdate, baseDate?)` — 独立した4手法の「票」を集計:

1. **四柱推命・日運**(−2〜+2): 日主×今日の日干の通変星。気流の総和を平均中心に票へ変換(劫財・傷官はきちんと向かい風になる)。星の意味(gloss)+過ごし方まで解説。
2. **四柱推命・月運**(±1): 月全体の気流の説明つき。
3. **干支の巡り**(±2): 今日の日支×生まれ年支。三合/支合=+2、冲=−2、同支=+1。関係の解説つき。
4. **月相**(±1): 満ちる時期=始める、欠ける時期=手放す。

合計→ 大吉(+5↑・約3%)/吉(約38%)/平(約35%)/静(約19%)/休(−3↓・約5%)。大吉と休には「年に数回」のレア度コピー。
**結論の言い回し**は `VERDICT_VOICE`(ランクごとに word 4種 × advice 4種、日×生年月日シード)——毎日同じ「攻めの日」にしない。

### スコア(score100)の設計

`dailyFortune(birthdate, baseDate?)`: `52 + (気流エネルギー−3)×16 + 結論の票×4.5 + 日替わりゆらぎ(三角分布±14)`、8〜100にクランプ。
- **分布目標(シミュレーション検証済み)**: 中央値65 / p5≈43 / p95≈87 / 60-80帯に収まるのは約53%(旧実装は96%が60-80帯で単調だった)。40以下・85以上の日がそれぞれ数%ちゃんと巡ってくる。
- **結論との整合**: ランク別スコア平均は 大吉≈89 > 吉≈74 > 平≈63 > 静≈52 > 休≈43 ときれいに降順(票がスコアに入っているため)。
- テーマ別メーターは0.5刻み(1.0〜5.0)。連続値をそのまま丸めるので3と4ばかりにならない。

### 風の予報(再訪の動機づけ)

- **今週の風位**(`weekOutlook`): 7日間のスコアを並べ、今日が今週何番目の風か・ピークがいつかを結果ヘッダー下に一行表示。結果の「文脈」が毎日変わる。
- **明日の気配**(`tomorrowHint`): 明日のスコアとの差から up/flat/down を判定し、**数字は明かさず**風向きの変化だけを予告(`TOMORROW_HINTS` 各4種)。ネタバレ禁止の原則のまま、翌日の観測動機をつくる。

**マインド言葉**は5ランク×(ベース10+テーマ別3×4)=110種、シードは日付×生年月日×カード×トップテーマ。
**ラッキー系プール**: アクション40 / カラー24 / アイテム24 / プレイス24。スコア別コメント(`SCORE_COMMENT`)は各レベル4種×5テーマ、シードは日付×テーマ×生年月日。
**リード文**は `TODAY_LEADS`(4種、日×人シード)。**結びの言葉**は `SENDOFF_LINES`(朝/昼/夕/夜×3種)— 朝の「いってらっしゃい」を夜に言わない。
**結果ヒーロー**はスコアを主役表示(結論の印章+`--num-display` の大きな数字+カウントアップ)。静・休の日の印章は金ではなく月白。票の内訳は±2票を▲▲/▼▼で強さごと見せる。

## 6. ホロスコープ

- **天体計算**: Paul Schlyter 近似(`planetLongitudes`)。水星〜海王星の軌道要素+木星/土星/天王星の摂動+冥王星の三角級数+月6項。精度±1°(娯楽用途に十分)。
- **出生図**: 10天体×星座+アスペクト(orb: 太陽月8/5° 他6/4°、上位7件)。
- **アセンダント**: 出生時刻×出生地(47都道府県 `PREF_GEO`)から GMST→地方恒星時→標準公式で計算。**日の出時に太陽黄経と一致することで検証済み**(誤差≒大気差1〜2°)。
- **今日の空**(毎日変わる): トランジットの月星座(`MOON_TODAY_DESC` 12種)+今日の天体×出生図のアスペクト上位3件+明日の月移動予告。
- **5年周期の流れ**: 土星の対出生土星象限(いつ)×トランジット土星のソーラーハウス=主戦場(どこで・生まれ月で12通り)×テーマ担当天体のサイン=あなたの型(どう進むか)。**同世代でも本文が変わることを1990年生8人で検証(7-8/8ユニーク)**。
- **今年の星模様**: 木星・土星のソーラーハウス(太陽星座起点の12部屋)。

## 7. 四柱推命・九星気学

- 三柱(年月日)+節入り簡易表。日主=日柱の干。
- **通変星**(`TSUHENSEI`): 10種それぞれに gloss(星の意味)/day/month テキスト+テーマ別重み。
- 「今日の気流」(日運・毎日変わる)/一週間/今月今年/12ヶ月(テーマ別ベスト月)。
- 九星: 本命星の気質+月盤の吉方位(五黄殺・暗剣殺・本命殺は除外)。

## 8. 相性診断

- **4層合算**: 星座エレメント30% + 九星五行25% + 干支(三合/支合/冲)25% + **日主の対話20%**(生まれた日の十干同士の通変星 `AISHO_BOND` — 同学年でも生まれ日で変わる)。
- **見え方(非対称)**: 五行の向き5関係 × 通変星10 = **50ラベル**(`PERSPECTIVE_LABELS`)+ニュアンス文10種。スコアも絆の質で±5揺れる。
- **一言キーワード**: バンド×関係ごとのプールからペア固有ハッシュで決定的に選択(25種、同じペアは常に同じ言葉)。
- **ふたりの取扱説明書**: 遊び方(エレメント組合せ10種 `AISHO_PLAY`)/ケンカの火種(最低点の層から `BOND_FRICTION`)/ふたりの吉日(向こう30日の日支×両者の年支を実スキャン)。
- **シェア画像**: 交わるふたつの円+中央スコア+非対称ラベル2行(1080×1920ストーリーズ)。

## 13. 開発運用メモ

- **監修ループ**: スクリーンショット一式→視点の異なるレビューエージェント(初心者目線/ビジュアル/コピー)→指摘反映→再検証、を繰り返す。
- **検証**: Playwright(`/opt/pw-browsers`)でE2E。フォームの生年月日は `bd-select` の各selectに値を入れて `change`(**bubbles: true 必須**)。
- **ロジック検証**: data.js+fortune.js を `new Function` で評価して Node 単体テスト(分布シミュレーション等)。
- コミットは日本語メッセージ。デバッグ用 `tarot-debug.html`(78枚+裏面の読み込み確認、noindex)。
